# Synthetic starter filter

`synthetic-filter.wav` is an original, generated mathematical FIR, **not a
measured cabinet, speaker or room**, and contains no third-party recording.

- Mono IEEE float32 RIFF WAV, 48000 Hz, 512 samples (10.667 ms).
- Generated by `syntheticIRBytes()` in `src/core/Impulse.cpp`: the impulse
  response of a one-pole 4200 Hz low-pass, minus its 90 Hz low-pass component.
  No peak/energy normalization or branded cabinet matching.
- SHA-256:
  `4a9ac650b2983ca0c49c138d11beccd2d0c8607ac9fccf47c537fbbf7bb7adae`.
- Generated for GuitarRack's M5 task on 2026-09-30. The binary embeds the same
  original analytic asset, so startup has no source-tree dependency. Tests
  verify the tracked bytes/identity and the independent system checksum agrees.
